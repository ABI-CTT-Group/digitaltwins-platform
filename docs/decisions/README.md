# Architecture Decision Records (ADRs)

This directory contains Architecture Decision Records for the digitaltwins-platform project.

## What is an ADR?

An ADR captures a significant design decision — the context, the alternatives considered, the choice made, and its consequences. ADRs are permanent, git-tracked records that serve as the project's decision history.

## When to create an ADR

Only when:
- A **real choice between alternatives** was evaluated
- A **deviation from an existing convention** or architecture was made
- A **non-obvious tradeoff** with future consequences was accepted

Do **not** create ADRs for routine fixes, minor refactors, or straightforward implementations.

## Naming convention

`YYYY-MM-DD-descriptive-title.md`
